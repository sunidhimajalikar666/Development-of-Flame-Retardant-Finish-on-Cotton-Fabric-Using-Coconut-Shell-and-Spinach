# Development of Flame Retardant Finish on Cotton Fabric Using Coconut Shell and Spinach

## Overview

This mini project explores an eco-friendly approach to imparting flame-retardant properties to cotton fabric using **coconut shell extract (CSE)** and **spinach juice (SJ)**. The study investigates the individual and combined effects of these natural materials and evaluates their flame-retardant performance through standard testing methods. 

## Objectives

* Extract natural flame-retardant agents from coconut shell and spinach.
* Apply the extracted agents to cotton fabric using suitable finishing techniques.
* Evaluate the flame-retardant properties of treated cotton.
* Study the effect of the finish on fabric strength, handle and comfort.
* Assess the durability of the finish after washing.
* Compare coconut shell, spinach and their combination as flame-retardant finishes. 

## Materials

* 350 GSM plain woven bleached cotton fabric
* Spinach leaves
* Waste coconut shells
* Anhydrous sodium carbonate (Na₂CO₃)
* Whatman No. 1 filter paper

The fabric used had **44 EPI, 22 PPI, 10/2s warp and 8/2s weft count**. 

## Methodology

1. Desize and scour the cotton fabric.
2. Extract coconut shell juice and filter it.
3. Extract spinach juice and filter it.
4. Adjust the extracts using sodium carbonate.
5. Treat cotton fabric with:

   * Coconut Shell Extract (CSE)
   * Spinach Juice (SJ)
   * CSE + SJ mixture in **1:1 ratio**
6. Treatment was carried out at **90°C for 60 minutes** with a **material-to-liquor ratio of 1:15**.
7. Air-dry and condition the treated samples before testing. 

## Testing

The treated and untreated fabrics were evaluated using:

* Limiting Oxygen Index (LOI)
* Vertical flammability test
* Char analysis
* Burning behaviour analysis

## Results

The LOI values obtained were:

| Sample           | LOI |
| ---------------- | --: |
| Untreated cotton |  18 |
| CSE treated      |  28 |
| SJ treated       |  30 |
| CSE + SJ treated |  34 |

The combined **CSE + SJ treatment achieved the highest LOI of 34**, compared with 18 for untreated cotton. 

In vertical flammability testing, the untreated fabric burned for about **50 seconds**, while the CSE, SJ and CSE+SJ treated fabrics showed substantially longer burning/afterglow times, with the CSE+SJ sample reported at **378 seconds**. 

## Key Findings

* Natural materials can be used to impart flame-retardant functionality to cotton.
* The combined CSE+SJ treatment showed higher LOI than the individual treatments.
* Increased char formation was associated with decreased flammability in the study.
* The approach provides a potential sustainable alternative for textile finishing. 

## Applications

Potential applications discussed in the project include:

* Home textiles
* Curtains
* Hospital textiles
* Table lamps
* Agro-textiles
* Other textile products where flame resistance is desirable.
